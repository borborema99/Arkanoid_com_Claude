# Arkanoid (Django)
- Jogo em Canvas e JS puro servido por Django. Fonte: jogo/static/jogo/game.js e style.css. Página: jogo/templates/jogo/index.html.
- Python do projeto: ~/.venvs/arkanoid/bin/python (não ative o venv, use o caminho completo).
- Rodar: ~/.venvs/arkanoid/bin/python manage.py runserver, depois abrir http://localhost:8000
- Depois de mudar o jogo, rode python build_dist.py (regera dist/arkanoid.html).
- Código em funções pequenas, com comentário de uma linha em português.
- Antes de editar, plano de no máximo 6 linhas e esperar meu "ok".
- Edite com Edit só nos trechos necessários. Não rode o jogo, não abra navegador, não crie testes.
- Resposta final com no máximo 3 linhas, sem resumo do código.
